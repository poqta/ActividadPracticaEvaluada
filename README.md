# Sistema de Gestión de Productos

**Estudiante:** Patricia Del Carmen Oquist Talavera 
**Asignatura:** Programacion de aplicaciones de escritorio

---

## Descripción del Proyecto

Este proyecto es una aplicación de escritorio desarrollada en **JavaFX** y conectada a una base de datos **PostgreSQL**. 

Permite gestionar un catálogo de productos a través de un panel con operaciones **CRUD** (Guardar, Actualizar, Eliminar) y realizar **búsquedas y filtros** por código, nombre, categoría y disponibilidad en stock. Además, incluye validaciones de interfaz y de base de datos para garantizar la integridad de los datos ingresados.
